## Как выкатывать обновление
1. Новый index.html → Add file → Upload files → Commit
2. В sw.js поднять версию: fath-v9 → fath-v10 (и так далее)
3. Пользователи получат обновление автоматически при следующем открытии

## Проверка версии на гитхабе
