# FATH — фитнес-игра

RPG-фитнес в одном HTML-файле: повторения превращаются в опыт, боссы получают урон, питомец растёт вместе с тобой, гарем даёт бонусы, а легендарные ящики падают с колеса фортуны.

## Как играть

1. Открой `index.html` в браузере (или по ссылке GitHub Pages)
2. Записывай повторения во вкладке «Упражнения» или наноси удары по боссу во вкладке «Битва»
3. Прогресс хранится в браузере (localStorage) — не чисти данные сайта, иначе сейв пропадёт

## Установка как приложение (PWA)

Открой сайт по HTTPS (GitHub Pages подходит) → в меню браузера выбери «Добавить на главный экран» / «Установить приложение». Появится иконка, полноэкранный режим и офлайн-работа.

## Публикация на GitHub Pages

1. Создай репозиторий и загрузи все файлы из этой папки (Add file → Upload files)
2. Commit changes
3. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save
4. Через 1–2 минуты игра откроется по адресу вида `https://ник.github.io/репозиторий/`
