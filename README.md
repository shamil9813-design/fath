# FATH — фитнес-игра (PWA)

## Как обновлять (главное правило)
1. Новый `index.html` заливаем через Add file → Upload files.
2. В `sw.js` поднимаем версию кэша: `fath-v10` → `fath-v11` → ... (каждый раз +1).
3. Commit. Через 1–2 минуты у игроков обновление появится само — ничего чистить не нужно.

## Файлы
- `index.html` — вся игра (маркер версии — первой строкой).
- `sw.js` — service worker: кэш + автообновление. Меняем только цифру версии.
- `manifest.json`, `icon-192.png`, `icon-512.png` — обвязка PWA, не трогаем.
- `ИНСТРУКЦИЯ.txt` можно удалить.

## Эксклюзивные фоны (только промокод)
- `PREMIERA` — фон «Премьера» (салют, золото). Код есть в газете на главном экране.
- Прочие: KISHBABAY, 8MARTA, LETO, OSEN2027, NEONIX, 8BIT, TIMESTOP, TOPKAPI, HAREM, BOSPHOR.
