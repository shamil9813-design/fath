# fath

**FATH** — фитнес-RPG в одном HTML-файле: реальная физуха конвертируется в прокачку героя, питомца и удары по боссам.

## Запуск

1. Открой `index.html` в браузере — этого достаточно.
2. Или сайт: https://shamil9813-design.github.io/fath/
3. На телефоне: Chrome → меню → «Добавить на главный экран» — игра встанет как приложение и заработает офлайн.

## Сохранение

Прогресс хранится в localStorage устройства. Перенос между устройствами — экспорт/импорт сейва в настройках игры.

## Промокоды

- `wormix100` — бонус
- `nazgul10` — бонус

## Обновления

Каждая новая версия игры поднимает версию кэша в `sw.js` (например, `fath-v4` → `fath-v5`), чтобы браузеры подтянули свежий файл.
